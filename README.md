## Hi, I'm Okuhle 🌱

I grew up in Keiskammahoek in the Eastern Cape, trained in horticulture, and now work with data and financial crime in Cape Town. In soil, in data and in code, I like to find the root of a problem and fix it properly.

I build small, careful web tools with **HTML, CSS and JavaScript**, and I work with **Python, SQL and Power BI** to turn messy data into clear answers.
